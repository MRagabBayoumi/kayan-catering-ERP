# منظومة كيان لإعاشة وتغذية المستشفيات (Kayan Catering ERP)

نظام ERP متكامل ومتخصص لإدارة شركات الكيترينج وتوريد الأغذية للمستشفيات والجهات الحكومية والخاصة، مبني بأحدث معايير **Laravel 12** و **PHP 8.5**، ومصمم وفق معمارية وتجربة مستخدم **Kayan ERP** ونمط وتصميم **Odoo Apps Hub** مع العزل التام للأقسام والصلاحيات الصارمة.

---

## 🚀 المعمارية وتجربة الاستخدام المعتمدة (System Architecture)

### 1. شاشة التطبيقات الرئيسية الموحدة (Odoo-Style Apps Hub)
- **بوابة الدخول الأولى (`/` أو `/home`)**: بمجرد تسجيل الدخول، ينتقل المستخدم إلى شاشة التطبيقات الرئيسية التي تعرض شبكة من الأيقونات الملونة لكافة الموديولات المصرح له بالوصول إليها.
- **إخفاء الشريط الجانبي في الشاشة الرئيسية**: يتم إخفاء الشريط الجانبي تماماً في شاشة البداية لتوفير واجهة نظيفة ومركزة تمنع تشتت المستخدمين.

### 2. العزل التام للأقسام والإدارات (Departmental Isolation)
- عند دخول المستخدم إلى أي إدارة (مثل المخازن، التكاليف، أو المالية)، يتحول الشريط الجانبي ليكون **مخصصاً بنسبة 100% لتلك الإدارة فقط**.
- **منع اختلاط الأقسام**: لا يمكن لموظف المخزن رؤية قوائم التكاليف أو المالية، ولا يمكن لمندوب المبيعات رؤية قوائم المشتريات أو الإعدادات.
- **هيدر الشريط الجانبي المحسن**:
  - تم وضع زر **«العودة لكل التطبيقات»** في أعلى الشريط الجانبي مباشرة مع سهم العودة لسهولة التنقل.
  - الحفاظ على زر طي وتوسيع القائمة الجانبية (`Desktop Sidebar Toggle`).
  - بانر تعريفي للإدارة الحالية بأيقونتها ولونها المميز.
- **تبويب «نظرة عامة» وشريط المؤشرات السريعة (`KPI Ribbon`)**:
  - يتصدر كل إدارة في الشريط الجانبي تبويب **«نظرة عامة»** (`layout-dashboard`).
  - تحتوي كل شاشة رئيسية على شريط إحصائي سريع مكون من 4 بطاقات تفاعلية (`kpi-card`) تعكس مؤشرات الأداء الحية للقسم.

## 🏛️ الهيكل التفصيلي للإدارات المستقلة (Core Modules)

### 1. إدارة المخازن والتشغيلات (Warehouse & Batches FIFO / FEFO)
- **تشغيلات الشراء (`Batches FIFO`)**: تتبع دقيق لأرصدة الباتشات وسعر التكلفة لكل باتش.
- **محرك الصلاحيات وتنبيهات `FEFO`**: ترتيب الصرف للأقرب انتهاءً أولاً، وتنبيهات ملونة للمنتجات الحرجة.
- **الجرد اليومي الأعمى (`Blind Audit`)**: يقوم أمين المخزن بإدخال الأرصدة الفعلية دون كشف الرصيد الدفتري لاكتشاف أي عجز أو زيادة فوراً.
- **أذون التحميل والصرف لسيارات المناديب**: رقابة دقيقة على البضاعة المنقولة من المخزن الرئيسي إلى مخازن السيارات.
- **حركة سيارات التوزيع ومصاريف النقل**: توزيع تكاليف الوقود والنقل المشترك بين المستشفيات والجهات المتعاقدة.
- **تسوية عهد المناديب اليومية (محاسب المخزن)**: مطابقة المنصرف الفعلي مع إشعارات استلام المستشفى والمرتجع للمخزن، وترحيل قيود التكلفة للـ ERP.

### 2. إدارة التكاليف والمقننات (Costing & BOM Management)
- **المقننات القياسية للوجبات (`Standard Meal BOM`)**: بطاقة مقادير تفصيلية لكل وجبة (لحوم، دواجن، أرز، خضار، توابل) بالجرامات.
- **حساب طلبيات المطبخ (`Daily Kitchen Orders`)**: احتساب خامات المطبخ آلياً بضرب أعداد النزلاء في المقنن المعتمد.
- **كشف انحرافات المقنن والهدر المالي (`Variance Analysis`)**: رصد ومقارنة المنصرف الفعلي بالمقنن المعياري.
- **مطابقة الموقع وكشف الهدر/العجز**: تسوية ومطابقة التكاليف بين شيف المطبخ ومدير الموقع.

### 3. تشغيل المواقع والمطابخ (Site Operations)
- **تعداد وتشغيل الموقع اليومي**: تسجيل أعداد الوجبات الفعلية للنزلاء (لحوم / دواجن / وجبات خاصة).
- **أذون صرف خامات المخزن الفرعي**: توثيق المنصرف من مخزن الموقع إلى مطبخ المستشفى.

### 4. إدارة المبيعات والمناقصات (Sales & Tenders)
- **دليل المستشفيات والتعاقدات**: إدارة العقود، الطاقة الاستيعابية، وتاريخ بدء وانتهاء التوريد.
- **سجل المناقصات والعطاءات (`Tenders`)**: متابعة الكراسات، التأمين الابتدائي، ودراسات الجدوى حتى الترسية.
- **أرشيف أسعار المنافسين**: أرشيف تحليلي لأسعار المنافسين في المناقصات السابقة لضمان الفوز بمناقصات العام القادم.

### 5. إدارة المشتريات والتوريدات (Procurement Management)
- **طلبات وأوامر الشراء والتوريد**: إدارة دورة الاحتياج، مقارنة عروض الأسعار، وتأكيد التوريد.
- **دليل وشبكة الموردين المعتمدين**: تكويد الموردين وأصناف التوريد المعتمدة.

### 6. إدارة الحسابات والمالية (Finance & Accounts)
- **الخزائن والبنوك وعهد المواقع النقدية**: متابعة حركة السيولة وعهد مديري المواقع لشراء الخبز والكايزر ومصاريف الطوارئ.
- **أذونات الصرف اللحظية**: اعتماد وصرف النقدية للمشتريات والمصروفات.
- **الوارد واعتماد التحصيلات**: تسجيل متحصلات المستشفيات والجهات.
- **حسابات الموردين والآجل وجدولة السداد**: متابعة الأرصدة المستحقة وجداول الدفعات وفترات الائتمان.
- **ترصيد وتسوية الموردين والعهد**: مذكرات التسوية والترصيد الدوري.
- **دفتر اليومية العامة والقيود التلقائية**: تسجيل حركات القيود المزدوجة الناتجة عن التشغيل.
- **دفتر الأستاذ العام وكشوف الحسابات**: استعراض الحسابات التفصيلية.
- **التفريدة والتحليل الشهري للجهات**: تفريدة الإيرادات والمصروفات وتكلفة الوجبات لكل مستشفى.
- **محضر تقفيل اليومية ومطابقة العجز للمالك**: تقفيل الإيراد والمصروف وحساب أرباح اليومية والمسحوبات والشراكة.

### 7. إعدادات النظام والصلاحيات (Settings & Access Control)
- **بيانات وهوية الشركة**: تعديل اسم الشركة، الهاتف، الشعار، الأرقام الضريبية والسجل التجاري.
- **حالة البرنامج**: التبديل الفوري بين الوضع النشط ووضع الصيانة.
- **إدارة المستخدمين والأدوار**: مصفوفة صلاحيات دقيقة (`Roles & Permissions`) لضمان عزل المهام.

## 🤖 مساعد كيان الذكي (Kayan AI Copilot)

مساعد ذكاء اصطناعي فوري متصل مباشرة بقاعدة البيانات عبر مسار `POST /ai/ask` ويجيب باللغة العربية الطبيعية عن:
- أرصدة اللحوم والدواجن والخامات وتواريخ الصلاحية.
- أسعار الوجبات في المناقصات السابقة وأسعار المنافسين.
- كشوف حسابات الموردين وآخر الدفعات.
- تكلفة وأرباح كل مستشفى ونسب الهدر والعجز وصافي الأرباح بعد المصاريف والضرائب.
- عدد الوجبات المنفذة اليوم وتوزيعها على المستشفيات.

## 📐 القواعد المعمارية الثابتة (Architectural Invariants)

1. **فصل كامل للأكواد (Zero Inline Code)**:
   - خلو جميع ملفات الـ `Blade` من وسوم `<script>` أو `<style>` أو `style="..."` أو `onclick="..."`.
   - يتم التحقق الآلي في كل اختبار عبر `BladeArchitectureSeparationTest`.
2. **المنفذ الافتراضي للتطوير**:
   - يتم تشغيل السيرفر المحلي دائماً على المنفذ **`7888`**:
     ```bash
     php artisan serve --port=7888
     ```
3. **التصميم وهوية Kayan ERP**:
   - استخدام الرموز المعيارية: `.kpi-card`، `<x-control-panel>`، `.erp-table`، `<x-icon>` SVG.
   - خط **Cairo** المدمج مع دعم كامل للاتجاه اليميني (`RTL`).

## 🚀 تشغيل وتجهيز المشروع (Quick Setup Guide)

```bash
# 1. سحب أحدث نسخة من المستودع
git pull origin main

# 2. تثبيت الحزم البرمجية
composer install
npm install

# 3. إعداد البيئة وقاعدة البيانات
php artisan migrate --seed

# 4. بناء الأصول وملفات الواجهة
npm run build

# 5. تشغيل السيرفر على المنفذ 7888
php artisan serve --port=7888
```
